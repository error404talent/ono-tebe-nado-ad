 Описание проекта

«Оно тебе надо» — это одностраничный сайт аукциона необычных вещей, в которые когда-то никто не верил. Проект представляет собой лендинг с информацией об аукционе, представленными лотами и контактными данными.

 Технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid

 Структура проекта

- `index.html` — основная HTML-страница.
- `styles/` — таблицы стилей CSS.
- `fonts/` — файлы шрифтов и их подключение.
- `images/` — изображения, логотипы и иконки.

 Запуск проекта

1. Склонируйте репозиторий на свой компьютер.
2. Откройте папку проекта.
3. Откройте файл `index.html` в браузере.
